# Expense Tracker

A Flutter personal-finance app for recording expenses and understanding monthly spending.

## Features

- Add expenses with a title, amount, date, and category.
- Review monthly totals and category spending.
- Track spending against an editable monthly budget.
- Save expenses and preferences locally between launches.
- Undo a deleted expense or clear saved data from Profile.

## Run

```sh
flutter pub get
flutter run
```

## Test

```sh
flutter test
```
